# 🎄 Secret Santa Badge Wall

Server dedicato per proiettare i badge su uno schermo separato.

## 🚀 Avvio

```bash
cd backend
python wall-server.py
```

Il server si avvierà su **http://localhost:5001**

## 📺 Utilizzo

1. Avvia il server principale (`be-server.py`) sulla porta 5000
2. Avvia il wall server (`wall-server.py`) sulla porta 5001
3. Apri **http://localhost:5001** sul dispositivo di proiezione
4. I badge verranno mostrati automaticamente in un carosello che scorre
5. La pagina si aggiorna automaticamente ogni 5 secondi per mostrare nuovi badge

## ✨ Caratteristiche

- 🎄 Design natalizio coerente con l'app principale
- 🔄 Auto-refresh ogni 5 secondi
- 🎠 Carosello automatico che scorre i badge
- ❄️ Animazioni natalizie (fiocchi di neve)
- 📱 Responsive e ottimizzato per proiezione
